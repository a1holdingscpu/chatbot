# DealiQ - Brand Guidelines & Logo Usage

## Logo Files

All logo files are located in `/app/frontend/public/`:

1. **logo.svg** - Square logo with icon (400x400px)
2. **logo-horizontal.svg** - Horizontal layout with tagline (600x200px)

## Typography

### Primary Font
- **Sans-serif**: Arial, Helvetica, system fonts
- **Weights**: 300 (Light), 400 (Regular), 600 (Semibold), 700 (Bold)

### Text Hierarchy
- **H1 (Hero)**: 48-64px, Bold
- **H2 (Section)**: 36-48px, Bold
- **H3 (Card Title)**: 24-32px, Semibold
- **Body**: 16-18px, Regular
- **Small Text**: 14px, Regular

## Logo Usage

### Clear Space
Maintain a minimum clear space around the logo equal to the height of the house icon.

### Minimum Sizes
- **Digital**: Minimum 120px width
- **Print**: Minimum 1.5 inches width

### Do's
✅ Use on white or light backgrounds (colored logo)
✅ Use white version on dark or colored backgrounds
✅ Maintain aspect ratio when scaling
✅ Use official logo files provided

### Don'ts
❌ Don't stretch or distort the logo
❌ Don't change colors or gradients
❌ Don't rotate the logo
❌ Don't add effects or shadows
❌ Don't place on busy backgrounds

## File Formats for Print

Current SVG files can be converted to:
- **PNG** (with transparency): For digital use, presentations
- **JPG**: For photos, web backgrounds
- **PDF**: For print materials, business cards
- **EPS**: For professional printing, large format

### Conversion Command (using Inkscape or ImageMagick)
```bash
# Convert SVG to PNG (high resolution)
inkscape logo.svg --export-png=logo.png --export-width=2000

# Convert SVG to PDF
inkscape logo.svg --export-pdf=logo.pdf
```
